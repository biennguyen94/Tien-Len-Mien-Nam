# Deployment (Docker on WSL, decision O5)

Status: deployed 2026-09-27 on the WSL Docker host, next to `openmu-web`.

## Topology

```text
Docker host (WSL2)
├── openmu-web   (other project)          host 4000
└── tien-len     image tien-len:latest    host 4020 → 4000, restart unless-stopped
                 compose project `tien-len` (deploy/docker-compose.yml)
```

- There is no database (O2). Rooms and games live in the container's memory, so **a restart or redeploy ends all running games**; players simply open a new room.
- The dev server (`mix phx.server`) uses port 4010, so both can run at the same time.
- Open **http://localhost:4020** (WSL forwards localhost to Windows).

## Environment variables

| Variable | Default | Meaning |
|---|---|---|
| `SECRET_KEY_BASE` | — (required) | Signs the session cookie, seat tokens and resume links. Generate with `mix phx.gen.secret`. Changing it logs everyone out (new player ids). |
| `PHX_HOST` | `localhost` | Public host name / IP (absolute URLs, e.g. resume links) |
| `PHX_URL_SCHEME` | `http` | `https` behind a TLS proxy |
| `PHX_URL_PORT` | `4020` | Public port in absolute URLs (`443` behind a TLS proxy) |
| `PHX_FORCE_SSL` | off | `true` only behind HTTPS (needs `X-Forwarded-Proto`) |
| `MAX_ROOMS` | `500` | Cap on open rooms (spam guard) |
| `WEB_PORT` | `4020` | Host port (compose variable) |

LiveView websockets use `check_origin: :conn`: they accept the origin the page was served from, so the same image works on localhost, a LAN IP or a domain.

## Operations

```bash
cd deploy
docker compose up -d --build      # first deploy / update after `git pull`
docker compose logs -f tien-len   # logs
docker compose restart tien-len   # ends running games
docker compose down               # stop
docker exec tien-len bin/tien_len rpc 'IO.inspect(TienLen.Lobby.list_rooms())'   # open rooms
```

Smoke test after a deploy:

```bash
curl -s -o /dev/null -w '%{http_code}\n' http://localhost:4020/                        # 200
curl -s -o /dev/null -w '%{http_code}\n' -X POST http://localhost:4020/ten -d name=x   # 403 (no CSRF token)
curl -s -o /dev/null -w '%{http_code} %{content_type}\n' http://localhost:4020/images/cards/AS.svg   # 200 image/svg+xml
```

## HTTPS / VPS

- On a VPS, set `PHX_HOST` (and `WEB_PORT`).
- Behind an HTTPS reverse proxy, also set `PHX_URL_SCHEME=https`, `PHX_URL_PORT=443` and `PHX_FORCE_SSL=true`.
- A proxy must forward websockets (`/live/websocket`).
